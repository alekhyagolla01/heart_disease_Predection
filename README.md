<h2>📌 Project Overview</h2>

<p>
  <b>Heart Disease Prediction</b> is a Machine Learning web application
  that predicts whether a person is likely to have heart disease based
  on medical input parameters.
</p>

<p>
  The project uses <b>Python, Scikit-learn and Flask</b> to train
  Machine Learning models and provide predictions through a web interface.
</p>

<h2>🔄 Machine Learning Workflow</h2>

<pre>
Dataset
   ↓
Data Preprocessing
   ↓
Feature Selection
   ↓
Data Scaling
   ↓
Model Training
   ↓
Model Evaluation
   ↓
Best Model
   ↓
Flask Web Application
   ↓
Heart Disease Prediction
</pre>

<h2>🧠 Machine Learning Models</h2>

<p>The project compares multiple classification algorithms:</p>

<ul>
  <li>Logistic Regression</li>
  <li>K-Nearest Neighbors (KNN)</li>
  <li>Naive Bayes</li>
  <li>Decision Tree</li>
  <li>Random Forest</li>
  <li>AdaBoost</li>
  <li>Gradient Boosting</li>
  <li>XGBoost</li>
</ul>

<p>
  Models are evaluated using <b>Accuracy, Confusion Matrix,
  Classification Report and ROC-AUC</b>.
</p>

<h2>🩺 Input Features</h2>

<ul>
  <li>Age</li>
  <li>Sex</li>
  <li>Chest Pain Type</li>
  <li>Resting Blood Pressure</li>
  <li>Cholesterol</li>
  <li>Fasting Blood Sugar</li>
  <li>Resting ECG</li>
  <li>Maximum Heart Rate</li>
  <li>Exercise-Induced Angina</li>
  <li>Oldpeak</li>
  <li>Slope</li>
  <li>Number of Major Vessels</li>
  <li>Thalassemia</li>
</ul>

<h2>🌐 Web Application</h2>

<p>The Flask application allows users to:</p>

<ol>
  <li>Enter patient information.</li>
  <li>Submit the data through an HTML form.</li>
  <li>Scale the input data.</li>
  <li>Apply the trained Machine Learning model.</li>
  <li>Display the prediction result.</li>
</ol>

<h2>🚀 How to Run Locally</h2>

<h3>1. Clone Repository</h3>

<pre>
git clone https://github.com/alekhyagolla01/heart_disease_Predection.git
cd heart_disease_Predection
</pre>

<h3>2. Create Virtual Environment</h3>

<pre>
python -m venv .venv
</pre>

<h3>3. Activate Virtual Environment</h3>

<p><b>Windows:</b></p>

<pre>
.venv\Scripts\activate
</pre>

<h3>4. Install Requirements</h3>

<pre>
pip install -r requirements.txt
</pre>

<h3>5. Run Application</h3>

<pre>
python app.py
</pre>

<p>Open the application in your browser:</p>

<pre>
http://127.0.0.1:5000/
</pre>
